# Data

No participant data are in this repository, and none will be added to it.

## Why

The 2021 survey was run in Qualtrics. The raw export carries IP addresses,
latitude and longitude, three timestamps per response, a Qualtrics response id
and a free-text field for native language. Stripping the direct identifiers is
not enough: the cleaned file still holds the response id, the recording date,
age, gender, education, country and native language, and on the rarer country
and language combinations that set is re-identifiable. The participants
consented to a study, not to publication of their responses.

This holds for the private repository as well. Data that a research ethics
process approved for local analysis does not become publishable by being pushed
to a repository that happens to be set to private.

## What is here instead

`synthetic/mas_synthetic.tsv` is generated by `tools/make_synthetic_data.R`. It
has the same columns as the Qualtrics export, the same response options, the
same coding of missing values and of "prefer not to say", and a two-factor
structure strong enough for the exploratory factor analysis to converge.

Everything substantive about it is invented. Item means, the correlation
between the two factors, and every relationship with HUMS and the Gold-MSI are
properties of the generator, not of music listening. The file exists so that a
reader can run the pipeline and watch it work, and for no other purpose.

## Running against the real data

Point `MAS_DATA` at a Qualtrics export with the 2021 column layout:

```r
Sys.setenv(MAS_DATA = "/path/to/export.tsv")
source("2026-reanalysis/RUN_ME.R")
```

The scripts under `2026-reanalysis/trials/` and `2026-reanalysis/bimodality/`
additionally need the saved R workspace from the 2021 run, named by
`MAS_WORKSPACE`. That workspace contains participant data, so it is not
distributed either.
